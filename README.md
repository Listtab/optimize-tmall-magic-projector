# 优化你的天猫魔屏投影仪

> 一台 2023 年出厂的天猫魔屏（MagicProjector_A1C，Android 5.1），从"开机先看广告、待机自己亮、系统应用乱跑"，改成"开机就是干净桌面、遥控器能待机、后台清清爽爽"。

这个仓库不是教程搬运，是**在一台真实机器上折腾了两天之后的完整记录**：能用的方案、踩过的坑、以及目前确实解决不了的问题，都写在里面。所有脚本和安装包都可以直接拿来用，也可以交给 AI 助手按 `AGENTS.md` 自动部署。

![改造前后对比](docs/images/before-after.jpg)

*上：原厂酷喵桌面，满屏内容推荐和会员入口；下：归藏电视，六个入口，右下角是「全部应用 / 其他信号源 / 设置」。*

## 做完之后是什么样

- **桌面**：归藏电视（开源、无广告），按 Android 5.1 重新编译过，首页六个入口：河南IPTV / OK影视 / 应用管家 / 桌面切换 / 系统设置 / 关机
- **关机**：首页最后一项按确认即进入待机（息屏），遥控器电源键可唤醒
- **后台**：酷喵、优酷服务、广告服务、少儿大厅、咪咕、系统屏保、天猫语音栈、华数认证、电池监控等 10 个系统包全部隐藏，不再自启
- **恢复**：装一个 `Home Fix` 小工具，随时一键切回原厂桌面或恢复被隐藏的组件

## 目录

```
apps/       自己编译的安装包（可直接装）
config/     首页配置示例（不含任何个人数据）
docs/       平台信息、部署步骤、测试结果、已知问题、AI 部署指南
scripts/    Windows 一键提权 / 一键关机
AGENTS.md   给 AI 助手的部署说明书（机器可读）
```

## 快速开始

**给人看**：读 [`docs/02-部署指南.md`](docs/02-部署指南.md)，按顺序执行，大约 20 分钟。

**给 AI 看**：把仓库地址丢给 Claude Code / Codex / Cursor，说一句：

> 读 AGENTS.md，按里面的步骤把这台天猫魔屏部署成归藏电视桌面，遇到失败用例按文档处理。

## 已知问题（务必先看）

| 问题 | 状态 |
|---|---|
| 遥控器长按电源键 → 菜单里的"关机"会变成重启 | **无解**，厂商 init 把 shutdown 映射成了 reboot，详见 [docs/04](docs/04-已知问题.md) |
| 遥控器电源键不能改键值 | 系统框架层处理，非应用可改；无障碍也拦不到 |
| root 每次开机失效 | Dirty COW 只改页缓存，重启还原；需要每次开机重跑脚本 |
| 系统应用无法真正卸载 | 系统签名校验拒绝，只能"隐藏"（等效禁用） |

这些不是没做完，是这台机器在系统层面就没有留口子。文档里写了完整的验证过程，避免后来者重复踩坑。
