# 05 交给 AI 自动部署

这个仓库是照着"AI 能读懂并自己动手"的标准写的：`AGENTS.md` 是机器可执行的部署手册，每一步都带验证命令和失败分支。

## 怎么用

把仓库克隆到本地，然后在 Claude Code / Codex / Cursor 里说：

> 读一下 AGENTS.md 和 docs/01-设备与平台.md，帮我按步骤部署这台天猫魔屏。电视 IP 是 192.168.1.50，adb 已经能连上。每一步做完先验证再继续，遇到文档里写的"无解"问题就跳过并告诉我。

AI 会自己去连 ADB、装应用、设置设备所有者、写首页配置、隐藏系统组件，并在每步之后验证。

## AI 能做的事

- 连接 ADB、安装应用、检查包名
- 设置设备所有者 / 激活设备管理员
- 写首页配置（`run-as` 方式，仅限 debug 签名的归藏）
- 调用 HomeFix 做隐藏与恢复
- 按验收清单逐项检查
- 遇到失败按 `AGENTS.md` 的索引处理

## AI 不该做的事（已在 AGENTS.md 里写死）

- 恢复出厂设置（会丢数据，必须人工确认）
- `pm uninstall` 系统应用
- `mount -o remount,rw /system`
- 隐藏 `com.yunos.tv.guide`（会让电源菜单消失）
- 在没备份 `run-as` 的情况下跑 Dirty COW

## 已知的"AI 也无解"

如果 AI 告诉你下面这些做不了，它是对的，不是它偷懒：

| 需求 | 原因 |
|---|---|
| 让遥控器电源键变成真关机 | 框架层处理，且厂商 init 把 shutdown 映射成 reboot |
| 卸载系统应用释放空间 | 系统签名校验拒绝 |
| 永久 root | Dirty COW 不持久，`/system` 不可写 |
| 改电源键键值 | 需要改只读分区或刷机 |

这些结论都有实测记录，见 [`03-测试结果.md`](03-测试结果.md) 和 [`04-已知问题.md`](04-已知问题.md)。

## 给 AI 的提示词模板

```
目标：把天猫魔屏（MagicProjector_A1C, Android 5.1）改造成归藏电视桌面。

约束：
1. 严格按 AGENTS.md 顺序执行，每步验证后再继续
2. 不要执行任何会丢用户数据的操作（恢复出厂、清除数据）
3. 遇到"无解"清单里的问题，跳过并在最后汇总
4. 所有涉及隐藏系统包的操作，先列出包名和作用，得到我确认后再执行

电视 IP：<填你的 IP>
```

## 让 AI 自己排错

文档里每条失败都有对应现象描述。AI 遇到报错时应该：

1. 先在 `AGENTS.md` 第 9 节"失败处理索引"里查
2. 查不到再看 `docs/04-已知问题.md`
3. 还是不匹配，把完整报错和当时的命令告诉用户，不要盲试
