# 02 部署指南

面向人看的完整步骤。全程大约 20 分钟，不需要 root，不需要拆机。

## 准备

1. 电视连上 Wi-Fi，记下 IP（设置 → 网络）
2. 电视开启 ADB 调试（开发者模式 → 网络调试）
3. 电脑装好 adb（或用仓库根目录的 platform-tools）
4. 电脑和电视在同一局域网

下文用 `<TV_IP>` 代替电视地址，例如 `192.168.1.50`。

```bash
adb connect <TV_IP>:5555
adb devices
```

看到 `device` 才能继续。

## 第一步：装两个应用

```bash
adb install -r apps/GuizangTV-0.3.0-a5.1.apk   # 桌面
adb install -r apps/HomeFix.apk                 # 设备所有者工具
```

> 归藏官方包要求 Android 8.0，这里是针对 5.1 重编的版本，**不要装官方包**，会报 `INSTALL_FAILED_OLDER_SDK`。

## 第二步：把 HomeFix 设为设备所有者

这是后面所有"隐藏应用 / 切换桌面 / 待机"的前提。

```bash
adb shell dpm set-device-owner tv.fix.home/.Admin
```

成功会打印 `Success: Device owner set to package tv.fix.home`。

如果提示"设备上已有账号"，需要先恢复出厂——**这一步会清空数据**，做之前想清楚。

## 第三步：切到归藏桌面

```bash
adb shell am start -n tv.fix.home/.MainActivity
```

电视上出现一个白色长列表，用遥控器选「2. 使用归藏电视」，按确认。

它会隐藏酷喵、显示归藏。之后按 Home 键应该进归藏。

## 第四步：配置首页

仓库里的 `config/home-items.sample.xml` 是六个入口的示例（河南IPTV / OK影视 / 应用管家 / 桌面切换 / 系统设置 / 关机）。

```bash
adb push config/home-items.sample.xml /data/local/tmp/home-items.xml
adb shell run-as io.github.op7418.guizangtv cp /data/local/tmp/home-items.xml \
  /data/data/io.github.op7418.guizangtv/shared_prefs/home-items.xml
adb shell am force-stop io.github.op7418.guizangtv
adb shell am start -n io.github.op7418.guizangtv/.FrameHomeActivity
```

**必须 force-stop 再启动**，否则应用会用内存里的旧配置覆盖你刚写的文件。这个坑我踩过，配置怎么改都不生效，最后发现是这个原因。

配置里的包名要和电视上实际装的应用一致，否则对应项会显示"暂时不可用"。

## 第五步：清理后台（可选）

打开 HomeFix，点「3. 隐藏优酷 / 广告 / 华数认证」。

会隐藏：优酷服务、广告服务、少儿大厅、咪咕爱唱、系统屏保、华数认证、天猫语音栈，一共 9 个包。

> 不要隐藏 `com.yunos.tv.guide`（导视）。实测隐藏后长按电源键的电源菜单会消失，按键直接变重启。HomeFix 已经把它排除。

想恢复：点「4. 恢复以上服务」。

## 第六步：让「关机」能用

首页最后一项「关机」会发广播给 HomeFix，由它调用 `lockNow()` 进入待机。

需要先激活设备管理员（设备所有者之外还要单独激活一次）：

```bash
adb shell dpm set-active-admin tv.fix.home/.Admin
```

然后测试：

```bash
adb shell am broadcast -a tv.fix.home.SLEEP
```

设备应该息屏。遥控器电源键能唤醒。

> 为什么用 `lockNow()`：这台机器的 `DevicePolicyManager.lockNow()` 实测效果就是待机息屏，而且它是设备所有者能调用的唯一"关屏"能力。`PowerManager.goToSleep()` 需要 `DEVICE_POWER` 签名权限，应用拿不到。

## 第七步：验收

| 检查 | 操作 | 期望 |
|---|---|---|
| 桌面 | 按 Home | 归藏 |
| 首页 | 目视 | 六项齐全 |
| 待机 | 选「关机」按确认 | 息屏 |
| 唤醒 | 按电源键 | 亮屏 |
| 后台 | `adb shell pm list packages \| grep youku` | 空 |
| 重启保持 | 断电重启 | 以上全部保持 |

## 常见问题

**`INSTALL_FAILED_UPDATE_INCOMPATIBLE`**
签名不一致。先 `adb uninstall <包名>`，再装。

**按 Home 弹出选择器**
说明还有第二个 HOME 应用可见（比如酷喵）。用 HomeFix 点「2. 使用归藏电视」重新隐藏。

**应用"消失"**
大概率被 HomeFix 隐藏了。点「9. 恢复 IPTV」或「4. 恢复以上服务」。

**ADB 老是掉线**
设备在重启或休眠，等 30 秒重连。如果一直连不上，断电重启电视。
