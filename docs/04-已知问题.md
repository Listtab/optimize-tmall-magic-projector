# 04 已知问题

这一页写的都是**目前解决不了**或者**只能绕过**的问题。不是没做完，是这台机器在系统层面没留口子。

## 1. 遥控器"关机"变成重启（核心问题）

### 现象

- 长按电源键 → 弹出「您希望进行哪种操作？关机 / 进入音响模式」
- 选择"关机"（或等 8 秒倒计时）→ 屏幕黑掉，但十几秒后自己亮起来
- 看 `uptime`：只有 30 秒左右，说明是**重启**，不是断电

### 排查过程

| 验证 | 结果 |
|---|---|
| 窗口归属 | 焦点窗口是 `GlobalActions`，属于 system_server 的框架对话框，不是某个第三方应用 |
| 改用 `adb shell reboot -p` | ✅ 真正断电，ping 不通、ADB 断开，直到手动开机 |
| 拔掉电源适配器再关机 | ❌ 仍然重启，排除"充电器触发开机" |
| 从系统设置 / 酷喵里关机 | ❌ 同样重启 |

### 根因判断

`reboot -p` 走的是内核 `reboot(RB_POWER_OFF)`，能真断电；而框架的"关机"走 `sys.powerctl=shutdown`，交给 init 处理。两者结果不同，说明**厂商的 init 把 `shutdown` 映射成了 reboot**，或者 GlobalActions 里调的就是 `reboot()`。

要修只有两条路：

1. 改 `init.rc` / `services.jar` → 都在只读分区，且需要平台签名
2. 刷第三方 ROM / Magisk 模块 → 需要 recovery 和解锁 bootloader，本机都没有

所以**在现有系统上无解**。

### 现在的应对

- 真关机：长按机身电源键（硬件断电），或电脑执行 `scripts/一键关机.bat`
- 日常待机：首页最后一项「关机」，或遥控器短按（行为不稳定，见下）

## 2. 电源键无法重映射

### 试过的方案

| 方案 | 结果 |
|---|---|
| 无障碍服务 + `canRequestFilterKeyEvents` | 服务确实绑定成功（`capabilities=8`），但 `onKeyEvent` 收不到 POWER |
| `input keyevent` 注入 | 能触发系统行为，但注入事件不符合"真实按键"路径，不能作为验证依据 |
| 改 `/system/usr/keylayout/*.kl` | 文件只读；Dirty COW 的修改只在页缓存，重启失效 |

电源键在 `PhoneWindowManager.interceptKeyBeforeQueueing` 阶段就被处理，早于无障碍和应用的按键分发。所以除非改系统，否则**应用层碰不到它**。

## 3. Root 不持久

- Dirty COW 修改的是页缓存，重启后 `run-as` 恢复成系统原版
- `/system` 无法 remount，装不了永久 su
- 结果是：每次开机都要在电脑上跑一次 `scripts/一键提权.bat`

这也意味着**任何依赖 root 的电视端功能都不可靠**，所以最终没有做"root 守护进程"方案。

## 4. 系统应用无法卸载，只能隐藏

`pm uninstall com.youku.taitan.tv` 会被系统拒绝（`can not uninstall system app`）。设备所有者可以 `setApplicationHidden`，效果等同：

- 不出现在应用列表
- 无法启动
- 重启后保持
- 可随时恢复

但**包体仍在**，占用的空间不会释放。

## 5. 包名冲突：河南IPTV = 早期的 "TV Live"

`com.brlf.tvlivelaunch` 这个名字听起来像某个桌面壳，实际是河南IPTV。项目早期把它写进"多余桌面"隐藏名单，导致每次切换桌面都把 IPTV 一起隐藏。

现在已从名单移除，并保留「9. 恢复 IPTV」按钮兜底。

## 6. 华数认证会清理应用

`com.yunos.ottauthclient` 里有 `OTTAuthBootReceiver`，开机跑认证。它会在后台校验应用列表。

目前的做法是直接隐藏这个包，认证不再执行。副作用：依赖认证的内置点播功能可能失效（本项目不使用）。

## 7. 系统屏保是广告来源

`com.android.dreams.phototable`（照片墙屏保）被厂商塞了推广图，无操作时会自动播放。隐藏后不再自动进入屏保。

## 8. 音效模式（音响模式）不可用

音响模式由 `com.yunos.music`（咪咕爱唱）承载。这个包已被隐藏以清理后台，因此音响模式入口不可用。如果以后需要，在 HomeFix 点「6. 恢复音响模式组件」。

## 9. 语音功能已关闭

天猫语音（`com.yunos.tv.alitvasr`）及两个 SDK 已隐藏。需要恢复时点「4. 恢复以上服务」，然后重启一次。

## 10. 触摸点击偶发不响应

归藏的首页项是给遥控器焦点设计的，用 ADB 注入触摸点击时偶尔不触发（遥控器选中按确认键正常）。不影响日常使用。
