# 06 归藏电视的修改说明

仓库里的 `apps/GuizangTV-0.3.0-a5.1.apk` 不是官方包，是拿 [op7418/guizang-tv](https://github.com/op7418/guizang-tv) v0.3.0 的源码，为 Android 5.1（API 22）重新编译并做了以下改动。全部改动都是源码级的，可复现。

## 为什么必须重编

官方包的 `minSdk 26`（Android 8.0），这台机器是 API 22，直接装会报：

```
Failure [INSTALL_FAILED_OLDER_SDK]
```

只改清单里的 minSdk 也不行，会走到 `INSTALL_FAILED_DEXOPT`——dex 里的 Java 8 特性 5.1 的运行时处理不了，必须重新编译。

## 编译配置

| 项 | 官方 | 本仓库 |
|---|---|---|
| compileSdk | 34 | 35（本机只有 platform-35） |
| minSdk | 26 | **22** |
| targetSdk | 34 | 34 |
| Gradle | 8.9 | 8.9 |
| JDK | 17 | 17 |

## 兼容性修改

### 1. 替换 5.1 没有的 Java 8 集合方法

| 文件 | 原代码 | 改为 |
|---|---|---|
| `HomeItems.java` | `Map.putIfAbsent` | `containsKey` + `put` |
| `HomeItems.java` | `Map.getOrDefault` | 取值判空 |
| `HomeSettings.java` | `Map.getOrDefault` | 取值判空 |
| `FrameHomeActivity.java` | `List.removeIf` | `Iterator.remove` |

### 2. 开启 core library desugaring

`java.util.function.Consumer` 这类类库在 API 24 才引入。设置页的 lambda 用了它，5.1 上会抛：

```
java.lang.NoClassDefFoundError: HomeSettings$$ExternalSyntheticLambda19
```

修复：

```gradle
compileOptions {
    coreLibraryDesugaringEnabled true
}
dependencies {
    coreLibraryDesugaring 'com.android.tools:desugar_jdk_libs:2.0.4'
}
```

这一条是设置页"一点就退"的根因。

## 功能改动

### 新增：电量显示

时钟下方加了一行电量文字（`HomeSurface` 的 `battery` TextView），由 `FrameHomeActivity` 每分钟读 `ACTION_BATTERY_CHANGED` 更新：

- 充电中显示「充电中 xx%」
- 未充电显示「电量 xx%」

### 新增：待机条目

首页支持一个特殊 id `action:shutdown`，点击后发送广播 `tv.fix.home.SLEEP`，由 HomeFix 调用 `lockNow()` 进入待机。

涉及改动：

- `HomeItems.validId()` 允许该 id
- `HomeItems.name()` 返回"关机"
- `HomeItems.DEFAULTS` 加入该 id（防止被 `save()` 过滤掉）
- `FrameHomeActivity.open()` 拦截并发送广播

### 删除：小米原桌面

- 首页默认项里的 `com.mitv.tvhome`
- 设置 →「电视与启动」里的「小米原桌面」入口（`a::stockHome`）

### 删除：右上角快捷按钮

早期版本在右上角加过「关机 / 音响模式」两个文字按钮，实测遥控器聚焦不到，已全部移除，改为左侧列表项。

## 首页配置

`config/home-items.sample.xml` 是六个入口的示例。写入方式（归藏是 debug 签名，可用 `run-as`）：

```bash
adb push config/home-items.sample.xml /data/local/tmp/home-items.xml
adb shell run-as io.github.op7418.guizangtv cp /data/local/tmp/home-items.xml \
  /data/data/io.github.op7418.guizangtv/shared_prefs/home-items.xml
adb shell am force-stop io.github.op7418.guizangtv
adb shell am start -n io.github.op7418.guizangtv/.FrameHomeActivity
```

**写文件前先 force-stop，写完后再次 force-stop 再启动**，否则运行中的进程会把内存里的旧配置写回去。这个问题排查了很久。

## 自己编译

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk   # 需要 platform-35
gradle :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 签名

本仓库的 APK 使用 debug 签名，和官方包**不兼容**：

- 装本仓库的包之前，如果装过官方版，需要先卸载
- 官方版升级时同样要先卸载本版本

这是 debug 签名的固有代价，换来的是可以直接 `run-as` 写配置。
