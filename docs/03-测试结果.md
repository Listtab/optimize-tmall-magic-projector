## 关机 / 待机

| 方式 | 结果 | 细节 |
|---|---|---|
| `adb shell reboot -p` | ✅ **真关机** | 断电后 ping 不通、ADB 断开，直到手动开机 |
| 电源键长按 → GlobalActions 菜单 → 关机 | ❌ 变重启 | 重启后 `uptime` 只有 30 秒，确认是重启不是断电 |
| 从系统设置 / 酷喵里的"关机" | ❌ 变重启 | 走的同一条框架路径 |
| 设备所有者 `lockNow()` | ✅ 待机息屏 | 需 `device_admin.xml` 声明 `<force-lock />` 并激活管理员 |
| 无障碍服务拦截 POWER 键 | ❌ 无效 | 系统在输入队列阶段就消费了电源键，服务收不到 |
| 应用直接调 `PowerManager.goToSleep()` | ❌ 无权限 | 需要 `DEVICE_POWER`（签名级） |
| 应用调 `ACTION_REQUEST_SHUTDOWN` | ❌ 无权限 | 需要 `SHUTDOWN`（签名级） |

## Root 尝试

| 步骤 | 结果 |
|---|---|
| Dirty COW（CVE-2016-5195）提权 | ✅ 成功，`uid=0(root)`，SELinux 域 `shell` |
| 重启后 root 是否保留 | ❌ 不保留，`run-as` 恢复原版 |
| `mount -o remount,rw /system` | ❌ `Invalid argument`（SELinux 拒绝） |
| 安装永久 su | ❌ 无法写入 `/system` |
| 用平台签名获取系统权限 | ❌ 框架是阿里云私钥签名，非 AOSP 测试密钥 |

## 一次踩坑记录

IPTP 应用"开机后被删"这件事，查了半天华数认证，最后发现是**我们自己的隐藏工具**干的：

`com.brlf.tvlivelaunch` 最初被当成"TV Live 桌面"写进隐藏名单，而它其实就是河南IPTV 的包名。每次切换桌面都会把它一并隐藏，表现出来就像"被删了"。

教训：**按包名做批量操作前，先确认这个包到底是什么**。后来在 HomeFix 里加了「9. 恢复 IPTV」专门兜底。
